# Internship Project Suite

This repository now includes a Python implementation for all requested mini-projects:

1. **Student Management System**
   - Input student name and marks
   - Display pass/fail
   - Store multiple students
2. **Machine Learning: Marks Prediction**
   - Train a simple linear model
   - Predict marks based on study hours
3. **Cloud Computing: File Backup Simulation**
   - Store and display file names
4. **Linux Project: File Management**
   - Create folders/files
   - Delete and list files
5. **Zero Client Project**
   - Includes a clear server-client explanation
6. **Cybersecurity Project: Login System**
   - Username/password verification
   - 3 attempts limit
7. **BONUS: Smart School System**
   - Integrates all modules in one workflow

## File

- `projects_suite.py` → complete implementation.

## Run

```bash
python3 projects_suite.py
```

For the full integrated demo (with login prompt), run in Python:

```python
from projects_suite import SmartSchoolSystem
SmartSchoolSystem().run_demo()
```
